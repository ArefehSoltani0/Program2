🔢 Multiples of Three – Recursive C# Console App

A lightweight educational C# program that **recursively** prints all positive multiples of 3 less than a given integer `N`.

Perfect for learning recursion, input validation, and console I/O in .NET.

---

✨ Features

- ✅ Fully recursive implementation (no loops)
- ✅ Robust input validation with error handling
- ✅ Cross-platform (runs on .NET 6+ / .NET Core / Framework)
- ✅ Clean, readable, and well-commented code
- Created by a passionate developer & language educator

---

## 🚀 Getting Started

### Prerequisites
- [.NET SDK](https://dotnet.microsoft.com/download) (v6.0 or later recommended)

### Run Locally


Create and enter project directory
dotnet new console -o MultiplesOfThree
cd MultiplesOfThree

 Replace `Program.cs` with the provided source code

 Run the application

```

You’ll be prompted to enter a number `N`. The program then displays all multiples of 3 less than `N`.
